# Coding Contract

TypeScript strict. Hindari any. File kebab-case; type/class PascalCase;
function/variable camelCase. Controller hanya transport concern.
Business logic tidak ditempatkan di controller. Gunakan dependency
injection. Error bisnis dipetakan secara konsisten. Config divalidasi
saat startup. Structured logging tanpa secret. Jangan menambah
abstraction tanpa kebutuhan nyata. Jangan duplikasi business invariant.
