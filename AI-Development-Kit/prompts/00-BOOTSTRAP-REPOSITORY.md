# Bootstrap Repository Prompt

Baca System Instructions dan seluruh AI Development Kit.

Anda sekarang bekerja sebagai repository coding agent.

Tugas pertama: 1. Verifikasi bahwa Anda memiliki akses filesystem dan
terminal. 2. Verifikasi exact checkpoint dan inspeksi hanya source-of-truth serta
permukaan yang relevan; jangan mengulang audit penuh pada input identik. 3. Tampilkan `git status` dan identifikasi package
manager/lockfile. 4. Baca manifest, scripts, workspace config, env
example, Prisma config/schema, Docker config, dan struktur test yang
tersedia. 5. Bandingkan repository dengan Project Requirements dan
Roadmap. 6. Perbarui `AI-Development-Kit/agent/REPOSITORY-MEMORY.md`
berdasarkan fakta aktual repository. 7. Jangan membangun modul produk
pada tahap bootstrap. 8. Jangan melakukan refactor. 9. Jalankan hanya
command discovery/validation yang aman. 10. Laporkan readiness untuk
Modul 01 dan blocker aktual jika ada.

Jangan tampilkan source code panjang di chat. Susun perubahan sebagai
exact-file payload; jangan edit branch main secara langsung.
